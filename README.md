# TODO

This project was really good to practice working with JSON and localStorage, as it provided many opportunities to set/update that data.

While the 'notes' visual idea was fun, I greatly overcomplicated it by setting text limits + doing so with a not mono-spaced font + relying on how it looks 'visually', instead of implementing a simpler character-based limit.

If I were to return to this project, I'd implement an option to add lists to the notes as well - but since that was out of the scope of the initial task, and i've already implemented a lot of extra things with my stick-it note design, I decided to skip on that feature for now. A few visual issues still remain (edge-case scenarios which occur after adding a lot of text, removing it, and trying to add some more + issue with the deadline button on 'edit' notes), but I consider that moving on to other projects would be the best decision for now.
